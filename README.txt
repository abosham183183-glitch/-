تحديث إرسال كود التحقق بالبريد

هذه النسخة تعدّل server.js فقط.

ما تم تغييره:
1) إرسال OTP عبر FormSubmit AJAX بنفس طريقة الموقع القديم.
2) رسالة OTP تحتوي على اسم العيادة، البريد، والرمز بالشكل القديم.
3) لا يتم إرسال كلمة السر أو OTP إلى المتصفح.
4) إذا فشل FormSubmit فلن يظهر للمستخدم أن الإرسال نجح؛ سيظهر خطأ حقيقي.
5) تم الإبقاء على قاعدة البيانات والجلسات والحماية.
6) تم الإبقاء على حد الحجز: اليوم وحتى 7 أيام قادمة.
7) حذف أدوار اليوم يحذف اليوم فقط ولا يحذف الحجوزات المستقبلية.

طريقة الاستخدام:
- استبدل ملف server.js الموجود في مستودع GitHub بهذا الملف.
- لا تنشئ Render Service جديداً.
- بعد Commit إلى main سيبدأ Render بالنشر تلقائياً.
